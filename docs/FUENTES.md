## Verificación y mantenimiento

Las páginas de Facebook pueden cambiar de nombre, URL o visibilidad. `data/estado_fuentes.json` sirve para detectar fuentes que acumulan fallos persistentes y revisarlas sin detener todo el catálogo.

## Agregar una fuente

```yaml
- id: fb_mi_fuente
  name: Nombre visible
  type: facebook_public
  source_class: eventos      # ticketera | eventos | venue | cultura_oficial | municipio | media
  tier: 1                    # 1, 2 o 3
  url: https://www.facebook.com/mifuente/
  region: Cochabamba
  city: Cochabamba
```

El planificador ordena por prioridad y antigüedad de lectura. Con el catálogo actual no hace falta ampliar el tamaño del grupo para sumar fuentes: se agregan a la rotación.
